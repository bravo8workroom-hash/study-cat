## 2. 정상 확인된 것

- 세션 1~3 잠금 순서, 카드 뒤집기·발음기호 표시, 포인트/스트릭 적립
- 수학 출발점 찾기 20문제 → 단계 배정(자연수·분수만 맞히면 4단계 배치), 승급/보정(mix) 동작
- 오답 저장소 적립 → 오답 다시 풀기 → 두 번 맞히면 졸업
- 오답노트 1단계(읽기)·3단계(직접 쓰기, 빈칸 미작성 시 진행 차단) → "3장 정리했어" 완료 화면 +30P
- 암기 카드(과학 세트) 카드 앞뒤·퀴즈 연결, 스펠링 1~3단계 화면
- 엄마 모드: 주간 리포트 6칸·제안 문구·리포트 복사, 내보내기 JSON(설계문서 11번 형식 + raw 백업), 요청문 6종

## 3. 남은 제안 (아직 손대지 않음 — 결정 필요)

1. **홈이 복잡해짐**: 자료가 쌓이면 홈에 스트립이 최대 6개(수학·암기 카드·문제 세트·스펠링·오답노트·오답 다시 풀기) 동시에 뜹니다. 설계 원칙("홈은 오늘의 세션 3개가 중심")과 어긋나므로 **한 번에 2개까지만** 우선순위대로 노출하는 안을 권합니다.
2. 세션 2 설명이 "오늘 단어 + 복습 0개"로 뜨는 날이 있음 → 복습이 0개면 "오늘 배운 단어로 퀴즈"처럼 바꾸는 편이 자연스럽습니다.
3. 잘못된 형식의 문제 세트를 불러오면 홈에는 "N문제"로 뜨지만 눌렀을 때 "풀 수 있는 문제가 없어" 토스트만 납니다. 불러오기 시점에 걸러 주는 편이 낫습니다.
