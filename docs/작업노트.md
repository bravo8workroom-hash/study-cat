  두 번 맞히면 다음 단계, 틀리면 한 단계 아래. 3단계를 두 번 맞히면 `spMaster`. 힌트를 쓰면 승급 없음.
  세션 3 = 카드 복습 → 스펠링(8단어)으로 바뀜. 홈 스트립(10단어, 하루 첫 완료 +20P)에서도 진입. 틀린 스펠링은 오답 저장소에 topic "스펠링"으로 적립.
- **발음**: 사전 API(dictionaryapi.dev)에서 실제 미국식 발음 오디오와 발음기호를 받아 `localStorage.catpron`에 캐시. 내장 100단어는 발음기호를 파일에 포함(오프라인에서도 표시).
  오디오도 미국 보이스도 없으면 🔊 버튼을 아예 숨김. en-US 보이스를 직접 골라 재생(Samantha/Ava/Google US English 등 우선) — 한국어 보이스가 영어를 읽어 콩글리시처럼 들리던 문제 수정. v3에도 동일 적용.

## 3단계 구현 내용 (데이터 주고받기 + 오답 저장소)
- **오답 자동 수집** `S.wrongLog[]`: `{k, subject, topic, q, a, chosen, opts, steps, n, ok, dates[]}`.
  영어 퀴즈(`answer()`)·수학/세트(`mathAnswer()`)의 오답에서 자동 적립. 진단(diag) 중에는 쌓지 않음.
- **오답 다시 풀기**: 홈에 스트립(오답 4개 이상일 때) → 최대 10문제, 보기·풀이까지 그대로 재출제.
  두 번 연속 맞히면 저장소에서 졸업(자동 삭제). 하루 첫 완료 시 +20P.
- **불러온 문제 세트**: `S.imp.quiz[]`. 홈 스트립 "새 문제 세트 · N문제" → 풀면 완료 표시 +30P, 오답은 저장소로.
- **불러온 단어**: `S.imp.words[]` → `applyImports()`가 `WORDS` 뒤에 append(중복 front 제외). 단어 id(index)는 append-only라 안전.
- **엄마 모드** `#scr-parent`: 설정 화면에서 비밀번호(기본 0000, 변경 가능)로 진입.
  기록 내보내기 / 파일 불러오기 / Claude 요청문 4종 복사 / 오답 저장소(과목 필터) / 불러온 세트 목록.
- **내보내기** `buildExport()`: 설계문서 11번 ③ 형식(type/exportedAt/wrongAnswers/weekStats) + `raw:S` 백업 겸용.
  weekStats에 english·math 정답률, weakTopics(오답 많은 주제 4개), mathLevel 포함.
- **불러오기** `handleImport()`: `words` / `quiz` / `export`(raw 복구, confirm) 3종. 형식 오류는 토스트로 안내.
- **상태 마이그레이션**: `migrate()`에 `wrongLog`, `imp{words,quiz,log}`, `settings.pin`, 일별 로그 `ag` 추가. 기존 기록 그대로 보존.
