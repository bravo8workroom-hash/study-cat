# 공부하는 고양이

중1 아이를 위한 학습 앱 (영어 단어 + 수학 연산 + 암기 과목 + 오답노트). 단일 HTML 파일, 설치 불필요.

- **아이 폰에서 열기**: https://bravo8workroom-hash.github.io/study-cat/
  (사파리에서 열고 공유 → "홈 화면에 추가"하면 앱처럼 쓸 수 있음)
- **기록 공유**: 아이 폰 엄마 모드에서 [공유 시작] → 가족 코드 생성 → 엄마 폰 엄마 모드 "아이 기록 보기"에 코드 입력. 백엔드는 우리집 다이어리와 같은 Supabase (`supabase.sql` 1회 실행 필요).
- 설정·엄마 모드 비밀번호: 000088 (설정 탭 진입부터 잠김)
- 로드맵 1~5단계 + v6(기록 공유·설정 잠금·삭제) 완료 (2026-08-07 기준). 상세는 `docs/작업노트.md`.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 최신본 (v5) — Pages로 배포되는 파일 |
| `build/` | 버전별 결과물 (app-v2~v5.html, patch2.js) |
| `docs/` | 개발지시서 · 작업노트 · v5 점검보고서 |
| `src/설계문서.md` | 전체 설계 (모든 기능 판단의 기준) |
| `src/앱/` | v1 완성본 + 개발용 템플릿(이미지가 `{{CAT_이름}}` 자리표시자) |
| `src/자산/` | 고양이 이미지 19종 + base64(cats_b64.json) |
| `src/자료수집/` | 아이 자료(문제집 사진·기록 내보내기) 모으는 곳 |
| `CLAUDE.md` | Claude 작업 지침 (말투·설계 원칙) |

## 개발 규칙 요약

- 수정은 `index.html`(=최신 build)에. 새 단계를 만들면 `build/app-v6.html`로도 남기고 작업노트 갱신.
- 기존 기록 보존: 상태 구조(S)를 바꾸면 `migrate()`에 마이그레이션 추가.
- 아이 화면은 단순하게, 낮은 점수는 아이에게 그대로 보여주지 않기. 상세는 `CLAUDE.md`.
