# 우리 아이 맞춤 학습 프로그램 — 전체 설계 문서

작성일: 2026-08-06
대상: 중학교 1학년 남학생 (공부에 흥미가 낮음, 영어 기초 부족, 전 과목 기본기 보강 필요)
사용 기기: 스마트폰 (주 사용)
운영 방식: 엄마가 Claude(코워크 + VS Code)와 함께 만들고 관리하는 우리집 전용 학습 앱

---

## 1. 이 프로그램의 핵심 원칙

기능보다 먼저 정해야 하는 것이 원칙입니다. 공부를 싫어하는 아이에게 기능이 많은 앱을 줘도 안 씁니다. 아래 5가지를 모든 설계의 기준으로 삼습니다.

**원칙 1 — 하루 1시간, 20분씩 3세션으로.**
하루 총 학습량은 1시간을 기본으로 하되, 한 번에 1시간이 아니라 20분짜리 세션 3개로 나눕니다(예: 학교 다녀와서 / 저녁 먹고 / 자기 전). 세션마다 "이것만 하면 이 세션 끝"이 눈에 보이게 미션을 구성합니다. 한 덩어리 1시간은 공부 싫어하는 아이에게 벽이지만, 20분짜리 3개는 넘을 수 있는 계단입니다.
다만 첫 1주는 적응 기간으로 20분×2세션(40분)부터 시작해 둘째 주부터 3세션으로 올리는 것을 권합니다. 첫날부터 1시간을 채우는 것보다, "매일 앱을 여는 습관"을 먼저 만들고 시간을 늘리는 쪽이 두 달 뒤 총 공부량이 훨씬 많습니다.

**원칙 2 — 시작 수준은 '창피하지 않게 쉬운' 수준.**
영어 기초가 부족하면 중1 단어장부터 시작하면 안 됩니다. 초등 필수 단어부터 시작하되, 앱 어디에도 "초등"이라는 표시를 하지 않습니다. 그냥 "레벨 1"입니다. 아이가 자존심 상하지 않고 맞히는 경험부터 쌓게 합니다.

**원칙 3 — 틀리는 것이 벌이 아니라 재료.**
오답은 혼나는 일이 아니라 "다음 문제를 만들어 주는 재료"로 다룹니다. 틀린 문제는 자동으로 모였다가 비슷한 유형으로 다시 나옵니다. 앱의 말투도 "틀렸어요 ❌"가 아니라 "이건 다시 만나게 될 거야" 톤으로.

**원칙 4 — 눈에 보이는 진행도.**
포인트, 연속 출석(스트릭), 레벨 같은 장치로 "쌓이는 것"을 보여줍니다. 다만 보상 설계는 엄마가 정합니다(예: 포인트 → 주말 게임 시간 교환 등, 앱은 포인트만 집계).

**원칙 5 — 엄마가 관리자, 아이는 사용자.**
아이에게는 "오늘 할 것"만 보입니다. 무엇을 넣을지, 어느 수준으로 낼지는 엄마 화면(관리 모드)에서 정합니다. 이 구조 덕분에 아이 화면은 단순하게 유지됩니다.

## 2. 전체 구조 한눈에 보기

이 프로그램은 두 부분으로 이루어집니다.

```
[아이용 학습 앱]  ←──────  [엄마 + Claude 작업실]
 스마트폰 HTML 앱            코워크 / VS Code의 Claude
 매일 쓰는 것                 재료를 만들어 넣는 곳

 · 오늘의 미션(3세션)         · 문제집 사진 → 유사 문제 만들기
 · 단어/암기 카드            · 오답 모음 → 변형 문제 만들기
 · 수학 연습                 · 교과서 내용 → 암기카드 만들기
 · 복습 세션(일일·주간)       · 오답노트 정리 + 정리법 코칭 문구
 · 오답 다시 풀기            · 앱에 넣을 데이터(JSON) 생성
 · 기록 내보내기(JSON)
```

**왜 이렇게 나누나요?**
사진을 읽고 문제를 새로 만들어내는 일은 AI(Claude)의 판단이 필요한 일이라 앱 혼자서는 못 합니다. 그래서 앱은 "공부하고 기록하는 곳", Claude는 "재료를 만드는 공장" 역할로 나눕니다. 앱과 Claude 사이는 **JSON 파일**(데이터를 담는 텍스트 파일)로 주고받습니다. 어렵게 들리지만 실제로는 "앱에서 [내보내기] 버튼 누르기 → 그 파일을 Claude에게 주기 → Claude가 만들어준 파일을 앱에서 [불러오기]"의 반복입니다.

### 일주일 운영 흐름 (예시)

1. 평일 매일: 아이는 앱에서 "오늘의 미션" 3세션 수행 (20분 × 3회 = 1시간, 세션 3은 복습)
2. 주 1~2회: 엄마가 앱에서 학습 기록·오답을 내보내기
3. 엄마가 Claude(코워크 또는 VS Code)에게 파일을 주고 "오답 변형 문제 만들어줘" / "다음 주 단어 세트 만들어줘" 요청
4. Claude가 만든 파일을 앱에 불러오기 → 다음 주 미션에 자동 반영
5. 시험 2~3주 전: "시험 모드"로 전환 (문제집 사진 → 유사 문제 루틴 가동)

## 3. 기능 모듈 상세 설계

### 모듈 A. 영어 — 단어·숙어·문장

**목표:** 기초 최하 수준에서 출발해 중1 교과서 수준까지, 매일 조금씩.

- **암기 카드:** 앞면 영어 / 뒷면 뜻. 탭하면 뒤집힘. 발음은 기기 내장 음성(TTS)으로 듣기 버튼 제공.
- **한 세션(20분) 분량:** 새 단어 6~8개 + 복습 단어 10개 안팎. (아이 반응을 보고 조절)
- **간격 반복(잊을 만하면 다시):** 맞힌 단어는 1일 → 3일 → 7일 → 14일 뒤에 다시 나오고, 틀린 단어는 바로 다음 날 다시 나옵니다. 암기 앱의 검증된 방식입니다.
- **퀴즈 형태 3종:** ① 뜻 고르기(4지선다) ② 영어 고르기 ③ 철자 입력(레벨이 오르면). 처음엔 ①만 써서 부담을 낮춥니다.
- **숙어·문장:** 단어가 자리 잡으면 숙어 → 짧은 문장(빈칸 채우기) 순으로 확장.
- **단어 데이터:** 초등 필수 800단어 → 중1 교과서 단어 순. 첫 세트는 Claude가 만들어서 넣어드립니다. 학교 교과서(출판사)를 알려주시면 그 교과서 단어 위주로 구성.

**단어 커리큘럼 (레벨 구성 — 새 단어 주 30~40개 페이스 기준):**

| 레벨 | 내용 | 분량 | 예상 기간 |
|---|---|---|---|
| 레벨 1 | 아주 기초 단어 (이미 아는 단어도 일부 포함 — 성공 경험용) | 100개 | 약 3주 |
| 레벨 2 | 초등 필수 단어 핵심 | 300개 | 약 8주 |
| 레벨 3 | 초등 고학년~중1 연결 단어 + 기초 숙어 진입 | 300개 | 약 8주 |
| 레벨 4 | 중1 교과서 단어·숙어 + 빈칸 문장 | 교과서 기준 | 이후 계속 |

- **숙어 진입 기준:** 레벨 3부터 한 세션에 숙어 2~3개씩 섞기 (별도 코너가 아니라 단어 카드에 자연스럽게 섞음)
- **문장 진입 기준:** 레벨 4부터 배운 단어로만 이루어진 짧은 문장 빈칸 채우기. 새 단어와 새 문장을 동시에 주지 않는 것이 원칙 (한 번에 하나만 새롭게)
- **철자 입력 퀴즈 진입:** 레벨 2 후반부터, 이미 여러 번 맞힌 단어에 한해서만

### 모듈 B. 수학 — 기본기 다지기

**목표:** 구멍 난 곳을 찾아 메우고, 중1 과정을 따라갈 발판 만들기.

- **진단부터:** 처음 시작할 때 가벼운 진단 문제로 어디부터 구멍인지 파악. "시험"이라 부르지 않고 "출발점 찾기"로 표현.

**출발점 찾기 (진단) 구성 — 총 20문항, 약 10~15분:**
자연수 사칙·혼합계산 4문항, 약수·배수·분수 4문항, 소수 3문항, 정수(음수) 3문항, 문자와 식 3문항, 일차방정식 3문항. 쉬운 것부터 배치하고, 연속으로 틀리면 그 영역은 중단(끝까지 다 풀게 하지 않음 — 좌절 방지). 결과로 시작 단계가 정해집니다.

**단계 사다리 (7단계):**

| 단계 | 내용 | 해당 학년 |
|---|---|---|
| 1 | 자연수 사칙연산·혼합계산 (구구단 구멍 점검 포함) | 초3~4 |
| 2 | 약수와 배수, 분수의 사칙연산 | 초5 |
| 3 | 소수 연산, 분수↔소수 변환 | 초5~6 |
| 4 | 정수와 유리수 (음수 연산) | 중1 |
| 5 | 문자와 식, 일차식 계산 | 중1 |
| 6 | 일차방정식 (풀이 + 활용 기초) | 중1 |
| 7 | 좌표평면과 그래프 | 중1 |

- **승급 규칙:** 해당 단계 최근 20문제 정답률 80% 이상이 이틀 연속이면 다음 단계로. 승급 시 축하 화면 + 보너스 포인트.
- **하향 규칙:** 정답률이 50% 아래로 떨어지면 조용히 한 단계 아래 문제를 섞어줌 (아이에게 "강등"이라고 알리지 않음).
- **학교 진도 병행:** 4단계 이상부터는 세션의 70%는 사다리 진도, 30%는 학교 현재 진도 문제로 배분 (시험 대비 공백 방지).
- **한 세션(20분) 분량:** 5~8문제. 연산 문제는 앱이 무한 생성 가능(숫자만 바꾸면 되므로 AI 없이도 됨).
- **풀이 과정 보기:** 틀리면 단계별 풀이를 한 줄씩 열어보는 방식(한 번에 다 보여주지 않음 — 어디까지는 알았는지 스스로 확인).
- **개념 문제(문장제 등)는 Claude 담당:** 유형 변형이 필요한 문제는 오답 데이터를 모아 Claude가 변형 문제를 만들어 공급.

### 모듈 C. 암기 과목 — 사회·과학·역사 등

**목표:** 시험 범위의 교과서 내용을 "외울 수 있는 형태"로 바꿔주기.

- **입력:** 엄마(또는 아이)가 교과서/프린트 사진을 찍어 Claude에게 전달.
- **Claude가 변환:** 핵심 정리 → 암기 카드(용어/뜻) → 빈칸 퀴즈 → OX 퀴즈 3종 세트로 만들어 앱에 넣을 파일 생성.
- **앱에서:** 영어 단어와 같은 카드·퀴즈 방식으로 학습. 같은 화면 구조를 재사용하므로 아이가 새로 배울 것이 없음.

### 모듈 D. 시험 모드 — 문제집 사진 → 유사 문제

**목표:** 시험 2~3주 전, 실제 시험 유형으로 연습량 늘리기.

**흐름:**

1. 문제집/프린트에서 연습하고 싶은 문제를 사진으로 찍음
2. 사진을 Claude(코워크 또는 VS Code)에게 전달: "이 문제들과 비슷한 유형으로 각 3문제씩 만들어줘"
3. Claude가 유사 문제 + 해설을 앱용 파일로 생성 → 앱에 불러오기
4. 아이가 앱에서 풀기 → 틀린 문제는 자동으로 오답 저장소에 들어감
5. 오답 저장소의 문제들로 Claude가 또 변형 문제 생성 → "같은 유형 다시 풀기"

이 순환(풀기 → 틀림 → 변형 → 다시 풀기)이 이 프로그램의 심장입니다. 틀린 유형만 골라서 반복되기 때문에 공부 시간 대비 효율이 가장 높은 부분입니다.

**시험 3주 플랜 (D-21 타임라인):**

| 기간 | 할 일 |
|---|---|
| D-21 ~ D-15 | 시험 범위 확인 → 교과서·프린트 사진 찍어 Claude에게 → 암기 세트 생성. 평소 세션을 시험 범위 내용으로 전환 |
| D-14 ~ D-8 | 문제집 사진 → 유사 문제 생성해 풀기. 오답이 본격적으로 쌓이는 기간 |
| D-7 ~ D-3 | 오답 변형 문제 집중. 주간 복습을 "범위 전체 모의 테스트"로 대체 |
| D-2 ~ D-1 | 오답만 다시 풀기. **새 문제 금지**(막판에 새로 틀리면 불안만 커짐). 평소보다 일찍 자기 — 시험 전날 밤샘은 그동안 공부를 버리는 행동 |

- 시험 모드 중에는 홈 화면에 D-day가 표시되고, 세션 구성이 위 타임라인에 맞게 자동으로 바뀝니다.
- 사진 찍기 요령: 문제가 잘리지 않게, 한 장에 2~4문제씩, 그림자 없이. 잘 찍힌 사진일수록 유사 문제 품질이 좋아집니다.

### 모듈 E. 오답노트 + 노트정리 코칭

**목표:** 오답노트를 만들어 주되, 만드는 방법 자체를 아이가 배우게 하기.

- **자동 수집:** 앱에서 틀린 모든 문제는 과목·유형·날짜와 함께 자동 저장.
- **Claude가 오답노트 초안 생성:** 문제 / 아이가 고른 답 / 왜 틀렸는지 / 핵심 개념 / 비슷한 문제 1개 — 이 5칸 구조로 정리.
- **코칭 장치 (중요):** Claude가 만들어 주는 오답노트에는 항상 마지막에 "이 노트는 이렇게 만든 거야" 한 줄 설명이 붙습니다. 예: *"틀린 문제는 ①문제 ②내가 쓴 답 ③틀린 이유 ④맞는 개념 순서로 적으면 돼. 다음엔 ③번 칸을 네가 직접 채워볼래?"*
- **점진적 넘기기:** 처음엔 Claude가 5칸을 다 채움 → 몇 주 뒤엔 "틀린 이유" 칸만 비워서 아이가 채움 → 나중엔 구조만 주고 아이가 작성. 이렇게 노트정리 능력 자체를 훈련합니다.

**넘기기 스케줄 (기준안 — 아이 상태 보고 늦춰도 됩니다):**

| 시기 | Claude가 하는 것 | 아이가 하는 것 |
|---|---|---|
| 1~3주차 | 5칸 전부 작성 + 코칭 한 줄 | 읽기만 |
| 4~6주차 | ③틀린 이유 칸만 비워서 작성 | ③틀린 이유를 자기 말로 쓰기 |
| 7~10주차 | ③④ 두 칸 비움 | 틀린 이유 + 핵심 개념 쓰기 |
| 11주차~ | 틀만 주고, 아이가 쓴 것에 검토 코멘트 | 오답노트 직접 작성 |

빨리 넘기는 것보다 안 끊기는 것이 중요합니다. 아이가 칸 채우기를 버거워하면 한 단계 뒤로 돌아가면 됩니다.

### 모듈 F. 복습 프로그램 — 세 겹의 복습

**목표:** 배운 것이 하루살이로 사라지지 않게, 복습을 시스템에 아예 박아 넣기. 복습은 아이가 "하기로 마음먹는 것"이 아니라 매일 미션에 자동으로 들어 있는 것이어야 합니다.

복습은 세 겹으로 돌아갑니다.

**① 일일 복습 (매일 세션 3, 20분):**
그날 세션 1·2에서 새로 배운 것 + 틀린 것을 그날 저녁에 다시 봅니다. 새 내용을 배우는 것이 아니라 오늘 것을 꺼내 보는 시간이라 부담이 가장 적고, 기억 정착 효과는 가장 큽니다. 자기 전에 하는 것을 권장합니다(아래 뇌과학 섹션 참고 — 자기 직전 복습한 내용은 수면 중에 장기기억으로 정리됩니다).

**② 주간 복습 (주말 1세션, 20~30분):**
이번 주 배운 전체 범위에서 앱이 자동으로 뽑은 미니 테스트. 맞히면 해당 내용의 다음 복습 주기가 길어지고, 틀리면 다음 주 일일 복습에 다시 등장합니다. 주간 복습 결과가 엄마용 주간 리포트의 재료가 됩니다.

**③ 누적 복습 (간격 반복, 자동):**
모든 카드·문제는 1일 → 3일 → 7일 → 14일 → 한 달 주기로 자동 재등장합니다. 아이도 엄마도 "뭘 복습할지" 고민할 필요가 없습니다 — 앱이 잊어버릴 때쯤 된 것만 골라서 내밉니다.

시험 기간에는 이 세 겹이 **시험 전 총복습 모드**로 전환됩니다: 시험 범위에 해당하는 것 중 틀린 적 있는 것부터 우선 출제 → 전 범위 훑기 → 마지막 2~3일은 오답만 집중.

### 모듈 G. 동기부여 시스템

- **포인트:** 미션 완료마다 적립. 화면 상단에 항상 표시.
- **스트릭(연속 출석):** "3일 연속!" 같은 불꽃 표시. 하루 놓쳐도 '프리패스' 아이템으로 1회 방어 가능(포기 방지).
- **레벨/칭호:** 포인트 누적으로 레벨업. 칭호는 아이가 좋아할 만한 재미있는 이름으로.
- **보상 교환:** 앱은 포인트만 보여주고, 실제 보상(게임 시간, 용돈 등)은 부모가 정하는 교환 규칙으로 운영. 이 규칙은 아이와 함께 정하는 것을 추천합니다.
- **주간 리포트(엄마용):** 이번 주 학습량, 정답률 변화, 가장 많이 틀린 유형을 관리 모드에서 확인.

**수치 설계 (초안 — 운영하며 조절):**

| 항목 | 포인트 |
|---|---|
| 세션 1개 완료 | +30P |
| 하루 3세션 모두 완료 보너스 | +30P (하루 최대 120P) |
| 주간 복습 완료 | +50P |
| 스트릭 7일 달성마다 | +100P |
| 수학 단계 승급 | +100P |
| 오답노트 칸 직접 채우기 | +20P |

- **레벨:** 500P마다 1레벨 상승. 성실하게 하면 주 1레벨 정도 오르는 속도 — 체감이 있어야 합니다.
- **프리패스(스트릭 방어권):** 300P로 구매, 월 2회 한도. 미리 사두게 유도(보험 개념을 배우는 부수 효과).
- **보상 교환 예시:** 500P = 주말 게임 30분 추가, 2,000P = 원하는 간식/소소한 물건 등. **환율과 품목은 반드시 아이와 함께 정하세요.** 포인트를 깎는 벌칙은 만들지 않습니다(포인트가 무서워지면 앱 자체를 피하게 됩니다).

## 4. 뇌과학 기반 학습 설계 — 왜 이렇게 만드는가

이 프로그램의 학습 방식은 기억 연구에서 효과가 검증된 원리들 위에 세웁니다. 각 원리가 앱의 어느 기능으로 구현되는지 함께 적습니다.

**① 인출 연습 (테스트 효과) — "읽기"가 아니라 "꺼내기"**
눈으로 다시 읽는 복습은 기억에 거의 남지 않습니다. 뇌는 정보를 "꺼내려고 애쓸 때" 그 기억의 회로를 강하게 만듭니다. 그래서 이 앱에는 "다시 읽기" 화면이 없습니다 — 모든 복습이 퀴즈(꺼내기) 형태입니다. 카드도 뜻을 먼저 보여주지 않고, 아이가 떠올려 본 뒤 뒤집게 합니다.

**② 간격 반복 — 잊어버리기 직전에 다시**
한 번에 몰아서 10번 보는 것보다, 잊을 만할 때 1번씩 5번 보는 것이 장기기억에 훨씬 강하게 남습니다(에빙하우스 망각곡선). 모듈 F의 1일→3일→7일→14일→한 달 주기가 이 원리의 구현입니다.

**③ 수면과 기억 정착 — 세션 3을 자기 전에**
낮에 배운 내용은 자는 동안 해마에서 대뇌피질로 옮겨지며 장기기억이 됩니다. 자기 직전에 복습한 내용은 이 정리 과정의 우선순위에 올라탑니다. 그래서 일일 복습(세션 3)의 권장 시간대가 "자기 전"입니다. 반대로 밤샘·수면 부족은 그날 공부를 통째로 버리는 것과 같다는 것도 아이에게 알려줄 가치가 있습니다.

**④ 분산 학습 — 1시간 몰아치기보다 20분×3**
같은 1시간이라도 나눠서 하면 매 세션이 "새로 꺼내기"가 되어 기억이 더 남고, 집중력이 유지되는 구간(중1 기준 15~25분)과도 맞습니다. 하루 1시간을 20분×3으로 설계한 것은 동기 문제만이 아니라 기억 효율 문제이기도 합니다.

**⑤ 교차 연습 — 한 과목만 파지 않기**
수학만 1시간 하는 것보다 영어→수학→복습처럼 섞으면, 뇌가 매번 "이건 어떤 종류의 문제지?"를 판단해야 해서 더 힘들지만 더 오래 남습니다. 세션 1·2를 서로 다른 과목으로 배치하는 이유입니다. 수학 세션 안에서도 오늘 유형만 내지 않고 이전 유형을 1~2문제 섞습니다.

**⑥ 바람직한 어려움 — 살짝 힘든 것이 기억에 남는다**
너무 쉬우면 뇌가 일을 안 해서 안 남고, 너무 어려우면 포기합니다. 목표 정답률을 80% 안팎으로 유지하도록 난이도를 조절합니다(전부 맞히면 다음 단계로, 많이 틀리면 한 계단 아래로). "창피하지 않게 쉬운 시작"(원칙 2)은 첫 진입용이고, 자리 잡은 뒤에는 항상 살짝 어렵게 유지합니다.

**⑦ 이중 부호화 + 맥락 — 글자만 외우지 않기**
단어는 글자로만 외우면 한 갈래 기억이지만, 소리(발음 듣기)·예문 속 상황·이미지가 붙으면 여러 갈래로 저장되어 꺼낼 문이 많아집니다. 단어 카드에 발음(TTS)과 쉬운 예문을 반드시 넣는 이유이고, 아이가 좋아하는 것(게임 등)을 예문 소재로 쓰는 이유입니다.

**⑧ 정교화 — "왜 틀렸지?"를 말로 만들기**
오답노트에서 "틀린 이유" 칸을 아이가 직접 채우게 하는 것(모듈 E의 점진적 넘기기)은 정교화 훈련입니다. 자기 말로 설명해 본 내용은 남의 설명을 들은 내용보다 훨씬 오래 남습니다. 수학의 "풀이를 한 줄씩 열어보기"도 같은 원리 — 전부 보여주기 전에 스스로 생각할 틈을 강제로 만듭니다.

이 8가지는 앱 기능 곳곳에 이미 반영되어 있어서, 아이는 원리를 몰라도 자동으로 이 방식으로 공부하게 됩니다. 다만 ③(수면)과 ⑥(살짝 어려운 게 정상이라는 것)은 아이에게 직접 말해주면 좋습니다 — "틀리는 게 뇌가 운동하는 중"이라는 걸 알면 오답을 덜 무서워합니다.

## 6. 기술 구성 (초보자용 설명)

- **형태:** HTML 파일 하나로 된 앱. 스마트폰 브라우저(크롬/삼성인터넷)로 열면 바로 작동. 홈 화면에 추가하면 일반 앱처럼 아이콘으로 실행됩니다. 설치·서버·비용 없음.
- **데이터 저장:** 학습 기록은 브라우저 안(localStorage)에 자동 저장됩니다. 단, 브라우저 데이터를 지우면 사라질 수 있으므로 주 1회 [내보내기]로 백업하는 습관을 권장합니다(내보내기는 어차피 Claude에게 전달할 때 필요하니 자연스럽게 됩니다).

- **주의할 점:** 아이 폰과 엄마 폰에서 각각 열면 기록이 따로 저장됩니다. 기본은 "아이 폰에서만 학습"으로 운영하고, 엄마는 아이 폰의 관리 모드를 쓰거나 내보낸 파일로 확인하는 방식을 추천합니다.

## 8. Claude에게 시키는 법 — 복사해서 쓰는 요청문

VS Code의 Claude(또는 이 코워크)에게 그대로 붙여 쓸 수 있는 요청문 예시입니다. `[ ]` 부분만 바꾸세요. "앱 불러오기 형식"은 11번 섹션의 JSON 형식을 말합니다 — 12번의 CLAUDE.md를 세팅해 두면 형식을 매번 말할 필요도 없습니다.

**단어 세트 만들기**
> 첨부한 단어 목록(또는 "초등 필수 단어 중 다음 50개")으로 우리 학습 앱용 단어 데이터를 만들어줘. 형식은 앱의 불러오기 형식(JSON)에 맞춰서. 각 단어에 뜻, 쉬운 예문 1개 포함.

**문제집 사진 → 유사 문제**
> 첨부한 사진은 [수학 문제집 일차방정식] 부분이야. 각 문제와 같은 유형으로 숫자와 상황만 바꾼 문제를 3개씩 만들어줘. 난이도는 원본과 같거나 살짝 쉽게. 해설 포함, 앱 불러오기 형식(JSON)으로.

**오답 변형 문제**
> 첨부한 파일은 아이의 오답 기록이야. 많이 틀린 유형 순서로, 유형당 변형 문제 3개씩 만들어줘. 해설은 중1이 이해할 수 있는 말로 짧게. 앱 불러오기 형식으로.

**오답노트 만들기 (코칭 포함)**
> 첨부한 오답 기록으로 오답노트를 만들어줘. 각 문제마다 ①문제 ②아이가 고른 답 ③틀린 이유 ④핵심 개념 ⑤비슷한 문제 1개 구조로. 마지막에 "오답노트는 이렇게 만드는 거야" 코칭 한 줄 추가. 이번에는 ③번 칸을 비워서 아이가 직접 채우게 해줘.

**교과서 사진 → 암기 세트**
> 첨부한 사진은 [사회 교과서 O단원]이야. 시험에 나올 핵심을 암기 카드 / 빈칸 퀴즈 / OX 퀴즈로 만들어줘. 앱 불러오기 형식으로.

- 첫 미션은 아이가 100% 맞힐 수 있는 수준으로 시작하세요. "어? 할 만한데"가 첫 목표입니다.
- 목표는 하루 1시간(20분×3세션)이지만, 첫 주는 2세션(40분)으로 시작해 둘째 주부터 3세션으로 올리는 것을 권합니다. 시간을 늘리는 것보다 "하루도 안 빼먹는 것"을 먼저 잡아야, 두 달 뒤 총 공부량이 더 많아집니다.
- 세션 3(복습)은 되도록 자기 전 시간대로 고정하세요. 수면 중 기억 정착 효과를 가장 크게 받는 자리입니다.
- 앱을 열었는지 확인은 하되, 결과(정답률)로 혼내지 않기로 아이와 약속하는 것을 추천합니다. 오답은 이 시스템의 연료이지 잘못이 아니라는 걸 아이가 믿어야 오답 데이터가 솔직하게 쌓입니다.
- 보상 규칙은 아이와 함께 정하세요. 자기가 정한 규칙은 지킬 확률이 훨씬 높습니다.

## 11. 데이터 형식 정의 (앱 ↔ Claude가 주고받는 파일)

이 형식만 지키면 어느 Claude(코워크, VS Code, 앱 내 안내문)에게 시켜도 앱이 바로 읽을 수 있습니다. 그대로 복사해서 "이 형식으로 만들어줘"라고 붙여 쓰세요.

**① 단어/암기 세트 (불러오기용):**

```json
{
  "type": "words",
  "setName": "레벨1-1주차",
  "subject": "english",
  "items": [
    {
      "id": "w0001",
      "front": "apple",
      "back": "사과",
      "example": "I eat an apple.",
      "exampleKo": "나는 사과를 먹어.",
      "level": 1
    }
  ]
}
```

(사회·과학 암기 카드도 같은 형식 — subject만 "social", "science" 등으로, front에 용어/질문, back에 답)

**② 문제 세트 (불러오기용):**

```json
{
  "type": "quiz",
  "setName": "일차방정식-변형-0812",
  "subject": "math",
  "items": [
    {
      "id": "q0001",
      "question": "3x + 5 = 20일 때, x의 값은?",
      "choices": ["3", "5", "7", "15"],
      "answer": 1,
      "explanation": "양변에서 5를 빼면 3x = 15, 양변을 3으로 나누면 x = 5",
      "topic": "일차방정식",
      "source": "문제집사진-0812"
    }
  ]
}
```

(answer는 choices에서 정답의 순서 번호, 0부터 셈. OX 문제는 choices를 ["O","X"]로)

**③ 학습 기록 (앱에서 내보내기 — Claude에게 전달하는 파일):**

```json
{
  "type": "export",
  "exportedAt": "2026-08-06",
  "wrongAnswers": [
    {
      "question": "…", "chosenAnswer": "…", "correctAnswer": "…",
      "subject": "math", "topic": "일차방정식",
      "wrongCount": 2, "dates": ["2026-08-03", "2026-08-05"]
    }
  ],
  "weekStats": {
    "sessionsDone": 18,
    "streak": 6,
    "accuracy": { "english": 0.82, "math": 0.71 },
    "weakTopics": ["분수의 나눗셈", "일차방정식 활용"]
  }
}
```

## 12. VS Code Claude 작업실 세팅 (자료 수집 → 생성 워크플로)

아이 자료를 모아뒀다가 Claude에게 시키는 공간입니다. 컴퓨터에 폴더 하나만 이렇게 만들어 두세요.

```
아이학습/
├── CLAUDE.md              ← Claude에게 주는 상시 지침 (아래 내용)
├── 앱/
│   └── 학습앱.html
├── 자료수집/               ← 아이 자료가 들어오는 곳
│   ├── 문제집사진/2026-08-12/
│   ├── 교과서사진/사회-2단원/
│   └── 기록내보내기/export-2026-08-06.json
└── 생성결과/               ← Claude가 만든 것이 나가는 곳
    ├── 단어세트/
    ├── 문제세트/
    └── 오답노트/
```

**CLAUDE.md에 넣을 내용 (그대로 복사해서 파일로 저장):**

```
# 아이 학습 프로그램 작업 지침

## 대상
- 중학교 1학년 남학생. 영어는 기초(초등 수준)부터, 수학은 기본기 보강 중.
- 공부에 흥미가 낮으므로 문제·해설·코칭 문구는 짧고, 쉽고, 다그치지 않는 말투로.

## 규칙
1. 해설은 중1이 혼자 읽고 이해할 수 있는 말로. 한 문장씩 짧게.
2. 문제를 만들 때는 원본과 같은 유형, 같은 난이도(또는 살짝 쉽게). 숫자·소재만 변경.
3. 모든 출력은 설계 문서 11번의 JSON 형식을 따를 것 (words / quiz / export).
4. 오답노트는 ①문제 ②아이가 쓴 답 ③틀린 이유 ④핵심 개념 ⑤비슷한 문제 구조.
   마지막에 "노트는 이렇게 만드는 거야" 코칭 한 줄 필수.
   현재 넘기기 단계: [1~3주차 — 전부 작성] ← 진행에 따라 이 줄을 수정
5. 칭찬·격려 문구는 과장 없이 담백하게. "천재네!" 금지, "어제보다 2개 늘었네" 방식.
6. 자료수집/ 폴더의 파일을 읽고, 결과는 생성결과/ 폴더에 날짜를 붙여 저장.
```

**운영 루틴:** 사진과 내보내기 파일을 자료수집/에 넣어두기만 하면 됩니다. 시간 날 때 VS Code에서 Claude를 열고 "자료수집 폴더의 새 파일 처리해줘"라고 하면, CLAUDE.md 지침에 따라 알아서 문제 세트·오답노트를 만들어 생성결과/에 저장합니다. 그 파일을 앱에서 불러오면 끝.

## 13. 예외 상황 대응 매뉴얼

계획대로 안 되는 날이 반드시 옵니다. 미리 정해두면 흔들리지 않습니다.

- **3일 이상 안 했을 때:** 다그치며 재개하지 않기. 분량을 절반(2세션→1세션)으로 줄인 "부활 미션"으로 다시 시작하고, 일주일에 걸쳐 원래 분량으로 복귀. 스트릭은 끊겼지만 "부활 보너스 +50P"로 재시작 자체에 보상.
- **특정 과목만 거부할 때:** 그 과목을 빼는 게 아니라 주 5회→2회로 줄이고, 빈 자리는 아이가 덜 싫어하는 과목으로. 완전히 빼면 다시 넣기가 훨씬 어렵습니다.
- **찍기(대충 빨리 누르기)가 의심될 때:** 문제당 응답 시간이 비정상적으로 짧은 날은 리포트에 표시됩니다. 아이를 추궁하기보다 난이도가 너무 높거나 분량이 부담스럽다는 신호로 읽고 조절하세요.
- **기록이 날아갔을 때:** 마지막 내보내기 파일을 불러오면 그 시점으로 복구됩니다. 주 1회 내보내기가 곧 백업입니다 (Claude에게 보낼 때 자연스럽게 하게 됨).
- **시험을 망쳤을 때:** 점수 이야기 전에 오답 데이터부터. "이번 시험이 다음 시험 문제 재료를 만들어줬다"가 이 시스템의 관점입니다. 실제로 시험지가 최고 품질의 오답 재료입니다 — 사진 찍어 Claude에게 주세요.

## 14. 아이에게 처음 소개하는 법

첫인상이 앱의 운명을 정합니다. 권장 시나리오:

1. **"공부 앱 깔았어"라고 하지 않기.** "네 전용으로 하나 만들었어(만들고 있어). 세상에 하나뿐인 거야"로 시작 — 자기를 위해 만들어졌다는 사실 자체가 중1에게는 힘이 셉니다.
2. **아이가 좋아하는 것이 반영된 부분을 먼저 보여주기** (예문 소재, 칭호 이름 등).
3. **보상 환율을 아이와 협상해서 정하기.** 자기가 정한 규칙은 지킬 확률이 훨씬 높고, 협상 과정 자체가 "이건 내 것"이라는 감각을 만듭니다.
4. **첫 세션은 옆에서 같이.** 100% 성공하도록 설계된 첫 미션을 하고, 포인트가 쌓이는 것까지 보고 끝내기.
5. **"틀리는 게 정상"이라고 미리 말해주기.** "틀린 문제가 다음 문제를 만들어. 틀려야 이 앱이 돌아가"라고 — 오답을 숨기지 않게 하는 것이 이 시스템 전체의 전제입니다.

## 15. 다음 할 일

이 문서를 보시고 방향이 맞으면, **1단계(영어 단어 앱)**부터 만들기 시작하면 됩니다. 그때 필요한 것:

1. 학교 영어 교과서 출판사 이름 (알려주시면 그 단어 위주로, 모르면 초등 필수 단어부터)
2. 아이가 좋아하는 것 2~3가지 (예문·칭호·말투에 반영해서 아이 것처럼 느끼게)
3. 하루에 시켜볼 만한 최소 시간 (5분? 10분?)

수정하고 싶은 부분이나 추가하고 싶은 기능을 알려주시면 문서를 고쳐가며 확정하면 됩니다.
