## 1. 현재 구현된 것 (1단계)

**화면:** 홈(3세션) / 카드 학습 / 4지선다 퀴즈 / 세션 완료 / 단어장 / 기록 / 설정

**기능:**
- 20분×3세션 구조: 세션 1 새 단어 카드(탭 뒤집기+발음 TTS) → 미니 퀴즈, 세션 2 오늘 단어+복습 퀴즈, 세션 3 자기 전 복습. 순서 잠금(1→2→3).
- 간격 반복: 맞히면 1→3→7→14→30일 주기로 재등장, 틀리면 다음 날. 단어별 box/due 관리.
- 동기부여: 세션 +30P, 3세션 보너스 +30P, 연속 출석 스트릭, 500P당 레벨(아기냥→전설냥).
- 영어 레벨 1 단어 100개 내장 (뜻·예문·해석 포함).
- 기록 탭: 주간 출석 그리드, 정답률, 자주 틀리는 단어.
- 설정: 아이 이름, 하루 새 단어 수(5/7/10), 기록 내보내기(JSON), 초기화.

**코드 구조 (공부하는고양이.html 내부):**
- `WORDS` — 단어 배열 [영어, 뜻, 예문, 해석]
- `CATS` — 고양이 이미지 base64 객체 (wave, grad, trophy, pencil, scratch, jump, flashcard, passed, comic, highfive, sleeplap, quiz, sleep)
- `S` — 전체 상태. `{points, streak, lastActive, words:{id:{box,due,wrong,seen}}, log:{날짜:{s:[3세션], newIds, wrong, quiz:[정답,전체]}}, settings}`
- `srs(id, ok)` — 간격 반복 갱신 / `startSession(n)` — 세션 진입 / `finishSession()` — 포인트·스트릭 처리
- localStorage 키: `catstudy`

**자산:** `자산/고양이/` 19종 (미사용분: calc 계산기냥→수학용, alarm 알람냥→리마인드용, gift 선물냥→보상교환용, idea, write, books). `개발용_템플릿.html`은 이미지가 `{{CAT_이름}}` 자리표시자로 되어 있어 코드 읽기/수정이 쉬움 — 수정 후 `자산/cats_b64.json`의 base64로 자리표시자를 치환하면 최종본이 됨.

## 3. 개발 시 주의 (필수)

1. **기존 기록 보존**: S 구조를 바꾸면 load()에 마이그레이션 코드 추가. 아이의 포인트·스트릭·단어 기록이 초기화되면 안 됨.
2. **고양이는 검정색 유지**: 어두운 배경에서는 흰/크림 동그라미 안에 (CSS의 .scard img, .fb img 패턴 참고).
3. **아이 화면은 단순하게**: 새 기능을 홈에 늘어놓지 말 것. 홈은 항상 "오늘의 세션 3개"가 중심.
4. **한 번에 한 단계**: 단계 하나 완성 → 아이가 써 봄 → 피드백 반영 → 다음 단계.
5. 문구 말투는 CLAUDE.md의 콘텐츠 생성 규칙을 따를 것.
