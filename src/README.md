# 아이 학습 프로그램 — 전체 자료 패키지

2026-08-06 기준. 이 폴더 하나면 어떤 Claude(클로드 디자인, VS Code의 Claude Code, 코워크)에서든 이어서 개발할 수 있습니다.

## 폴더 구성

```
아이학습_전체자료/
├── README.md                  ← 지금 보는 파일
├── CLAUDE.md                  ← Claude에게 주는 상시 지침 (프로젝트 폴더 최상위에 두세요)
├── 설계문서.md                 ← 전체 설계 (15개 섹션)
├── 다음단계_개발지시서.md       ← 현재 구현 상태 + 이어서 만들 것 명세
├── 앱/
│   ├── 공부하는고양이.html      ← 현재 완성본 (1단계, 아이 폰에서 바로 사용 가능)
│   └── 개발용_템플릿.html       ← 이미지가 {{CAT_이름}} 자리표시자로 된 개발용 버전
├── 자산/
│   ├── 고양이/*.png            ← 투명 배경 고양이 19종
│   └── cats_b64.json          ← 위 이미지들의 base64 (템플릿에 넣을 때 사용)
└── 자료수집/                   ← 아이 자료(사진·기록 내보내기)를 여기에 모으세요
    ├── 문제집사진/
    ├── 교과서사진/
    └── 기록내보내기/
```

## 이어서 개발을 시키는 법

새 Claude 세션에서 이 폴더를 열고(또는 업로드하고) 이렇게 말하면 됩니다:

> CLAUDE.md와 설계문서.md, 다음단계_개발지시서.md를 읽고,
> 로드맵 2단계(수학 기본 연산)를 앱에 추가해줘.

한 번에 한 단계씩 시키고, 아이가 써 본 반응을 보고 다음 단계로 넘어가는 것을 권합니다.
